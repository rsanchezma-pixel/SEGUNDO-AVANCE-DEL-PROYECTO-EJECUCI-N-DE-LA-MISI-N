# SEGUNDO-AVANCE-DEL-PROYECTO-EJECUCI-N-DE-LA-MISI-N
Descripción del proyecto: Misión Órbita

El proyecto Misión Órbita consiste en desarrollar un simulador básico de exploración espacial utilizando el lenguaje de programación Python. Su objetivo es aplicar los conocimientos adquiridos en el curso Principios de Programación 1 mediante la creación de algoritmos que permitan planificar, ejecutar y evaluar misiones espaciales.

En este segundo avance se desarrollan cuatro ejercicios relacionados con la selección del destino y autorización de la misión, simulación del viaje, actividades de exploración científica y evaluación del regreso de la tripulación a la Tierra. El sistema deberá administrar recursos como combustible, oxígeno, energía y provisiones, considerando su consumo y las condiciones necesarias para completar la misión.

Para cada ejercicio asignado se solicita elaborar una tabla de variables, un diagrama de flujo, el código fuente en Python y casos de prueba con evidencias de ejecución. Además, se deben aplicar estructuras condicionales simples, múltiples y anidadas, ciclos, contadores, acumuladores y variables de control, respetando las buenas prácticas de programación.

Finalmente, el proyecto requiere documentar las soluciones y mantener un repositorio Git que evidencie el desarrollo progresivo del trabajo.
